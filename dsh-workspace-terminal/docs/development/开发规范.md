# 开发规范

> 面向后续维护者：宿主直接加载 `lib/` 构建产物，**改 `src/` 后必须 `node scripts/build.mjs` 重建**。

## 1. 技术栈

- **TypeScript + esbuild**：`src/` → `lib/`（client iife + host esm）。
- **client 不 import 运行时 react**：react 为种子模块，经 `__ModuleLoader__.load` factory 注入。
- **host 用 node API**（node-pty / ws / node:http / node:stream）。

## 2. 目录结构

```
src/
├── index.ts              # host：注册 /ws/terminal + 鉴权 + WS↔pty 桥
├── pty-manager.ts        # node-pty 生命周期（懒加载 / sessionId:tab 隔离 / 降级）
└── client/
    ├── index.ts          # __ModuleLoader__.load 包装（注入 React）
    ├── plugin.ts         # registerWidget 注册「终端」tab + 声明式设置 + 缺宿主守卫
    ├── terminal.tsx      # widget 外层容器（按主题设背景）
    └── xterm-pane.tsx    # xterm.js + FitAddon + CSS 内联 + WS 连接 / resize 上报
```

## 3. 构建约定（不要破坏）

- **client 打 iife，种子模块 external**：`react` / `react/jsx-runtime` / `@deepseek-ai/*`。
- **host 外部化 `node-pty` / `ws`**：原生 / 运行时依赖，由 profile 的 node_modules 解析，不要打包。
- **CSS 按 text 内联**：build 的 `loader: { '.css': 'text' }`，xterm CSS 注入 `<style>`。
- **client 入口走 `__ModuleLoader__.load`**：不要直接 export 模块级副作用。

## 4. 运行时约定（不要破坏）

- **WS 路由鉴权 `authorize()` 必须保留**：Host/Origin 信任 + `dsh-auth-*` cookie 检查；
  删掉 = 未鉴权 WS。
- **WS 协议**：文本帧 = 终端输入；JSON `{type:'resize',cols,rows}` = 尺寸；解析失败按输入处理。
- **node-pty 懒加载**：缺失时 `available=false`，客户端显示降级提示，不拖垮插件 / 不崩 dsh web。
- **缺工作台宿主守卫**：`apply()` 开头 `if (!ctx.workspace)` 跳过注册并 `console.warn`，
  不要直接解引用 `ctx.workspace`。
- **对宿主插件的引用**：仅允许在用户可见的诊断消息里出现 `dsh-workspace-sidebar`
  （帮助定位缺宿主）；逻辑上不做任何硬依赖，代码注释只描述机制本身。

## 5. 原生模块放行（node-pty）

`node-pty` 原生构建会被 pnpm 拦截，需放行：

- 本插件 `pnpm-workspace.yaml` 已含 `allowBuilds: esbuild/node-pty: true`，插件目录内
  `pnpm install` 直接生效。
- 若 profile 侧拦截：在 `~/.dsh/profiles/web/pnpm-workspace.yaml` 的 `allowBuilds` 加
  `node-pty: true`（或 `pnpm approve-builds`）后重装。

## 6. 构建 / 验证

```bash
pnpm install
node scripts/build.mjs      # esbuild → lib/client.js（含 xterm）+ lib/index.js
dsh plugin --profile web add <本插件目录>
dsh web --no-open --port 57441
```

- 冒烟：开工作台点「终端」tab，应见真 shell 提示符；输入命令应回显；多开终端互不影响。
- esbuild 优先解析本地 `node_modules`，缺失则回退共享同仓库其它插件已装的 esbuild。
